Prompt System Usage Examples for run_vllm_post_editing.py

The script now supports flexible prompt templates through the --prompt argument.

=== Available Prompt Keys ===

1. "default" - Standard translation prompt (same as original)
2. "biblical" - Specialized for religious/biblical texts
3. "formal" - For academic and formal documents
4. "conversational" - For natural, everyday language
5. "post_editing" - For improving machine translations
6. "context_aware" - Considers cultural nuances
7. "minimal" - Very simple, direct translation

=== Usage Examples ===

# Default prompt (same as before)
python run_vllm_post_editing.py \
  --model "google/gemma-3-1b-it" \
  --source_path "/path/to/source.txt" \
  --target_path "/path/to/target.txt" \
  --src "en" \
  --tgt "id" \
  --prompt "default"

# Biblical translation
python run_vllm_post_editing.py \
  --model "google/gemma-3-1b-it" \
  --source_path "/path/to/bible_source.txt" \
  --target_path "/path/to/bible_target.txt" \
  --src "en" \
  --tgt "id" \
  --prompt "biblical"

# Post-editing mode (for improving existing translations)
python run_vllm_post_editing.py \
  --model "google/gemma-3-1b-it" \
  --source_path "/path/to/source.txt" \
  --target_path "/path/to/target.txt" \
  --src "en" \
  --tgt "id" \
  --prompt "post_editing"

# Minimal/direct translation
python run_vllm_post_editing.py \
  --model "google/gemma-3-1b-it" \
  --source_path "/path/to/source.txt" \
  --target_path "/path/to/target.txt" \
  --src "en" \
  --tgt "id" \
  --prompt "minimal"

=== Variable Placeholders ===

The prompts support the following variables:
- {src_lang_name} - Full source language name (e.g., "English")
- {tgt_lang_name} - Full target language name (e.g., "Indonesian")
- {src_text} - Source text to translate
- {tgt_text} - Target text (used in few-shot examples)

=== Adding Custom Prompts ===

To add your own prompts, edit src/prompt.py and add to the PROMPTS dictionary:

```python
"your_prompt_key": {
    "system": "Your system instruction with {tgt_lang_name} placeholder",
    "user_template": "User message template with {src_text} and {src_lang_name}",
    "assistant_template": "{tgt_text}"
}
```

=== Output Files ===

Results are saved with prompt information in the filename:
- Translations: translate_res/[model]_[source]_[src]_[tgt].tsv
- Metrics: translate_res/[model]_[source]_[src]_[tgt]_metrics.json

Both files will now include the specific prompt used for the translation.
